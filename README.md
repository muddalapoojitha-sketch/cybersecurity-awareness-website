# 🔐 Cybersecurity Awareness Website

## 📌 About the Project
The Cybersecurity Awareness Website is an educational website that helps users understand basic online security and safe internet practices.

## 🎯 Objectives
- Create awareness about cybersecurity.
- Help users identify phishing attacks.
- Explain password safety.
- Promote safe social media usage.
- Provide safe browsing tips.
- Educate users about malware and email security.

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Git & GitHub

## ✨ Features
- Cybersecurity awareness information
- Phishing awareness
- Password safety tips
- Social media safety
- Malware awareness
- Email safety
- Safe browsing tips
- Cybersecurity quiz
